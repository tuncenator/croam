# croam

Cross-host claude-code session manager.

croam tracks ownership, enables attach/peek/claim/fork across machines via
SSH + syncthing, and wraps claude in tmux so sessions persist across terminal
disconnects. It supersedes the local `cctakeover` script by adding multi-host
awareness and an explicit ownership model.

---

## Install

Requires Python 3.11+ and uv.

```bash
# Install into the uv tool store (adds `croam` to PATH via uv tools).
uv tool install --editable .

# Or, if you want to run from the source tree directly:
uv sync
uv run croam --help
```

---

## First run

```bash
croam doctor
```

`doctor` checks that config exists, SSH to each configured host works,
syncthing state is readable, and ownership files are consistent. It prints
a per-check status line and exits 0 only when everything is healthy.

On the first run it will report a missing config file. Create
`~/.config/croam/config.toml` (see Configuration below) and re-run.

## Verb cheat sheet

```
croam                   Interactive picker (fzf), filtered to $PWD by default.
croam ls                Non-interactive list. --json for scriptable output.
croam attach <sid>      Adopt the live session; recursive over SSH to owner.
croam peek <sid>        Read-only view. Live tmux -r if reachable, transcript otherwise.
croam claim <sid>       Transfer ownership to this host.
croam fork <sid>        Create a new session branched from an existing JSONL.
croam launch            Start a new claude session inside tmux (shim entry point).
croam doctor            Diagnose config, SSH, syncthing, ownership consistency.
```

Common global flags:

```
--all, -A       Show sessions from all hosts and directories.
--json          Emit JSON instead of human-readable output.
--host HOST     Limit to a single host.
--last N        Window in days (default 30).
--debug         Enable DEBUG-level logging to ~/.local/state/croam/croam.log.
```

## Configuration

Configuration lives at `~/.config/croam/config.toml`.

Full schema and all options are documented in
`docs/specs/2026-04-30-croam-design.md`, section 10.

Minimal working config:

```toml
[self]
hostname = "vicar"

[hosts.vicar]
ssh = "vicar"
sync = true

[hosts.stormtree]
ssh = "stormtree"
sync = true

[storage]
state_root = "~/Sync/croam"

[discovery]
mode = "syncthing"

[ownership]
claim_verify = "ssh-strict"
```

## Shim install (replacing the system `claude` binary)

croam works best when every `claude` invocation is automatically wrapped in
tmux. The shim install renames the system `claude` to `claude-real` and
writes a small wrapper that execs `croam launch "$@"`.

### Automatic (helper script)

```bash
# Verify prerequisites without making changes.
bash scripts/install-shim.sh --self-check

# Install.
bash scripts/install-shim.sh

# Undo.
bash scripts/install-shim.sh --uninstall
```

The script never calls sudo. If the directory containing `claude` is not
writable by the current user, it exits 1 with instructions to install croam
into a user-writable prefix such as `~/.local/bin` first.

### Manual steps

1. Find where claude lives: `which claude`
2. Rename it: `mv $(which claude) $(dirname $(which claude))/claude-real`
3. Write a wrapper at the same path:

```bash
#!/usr/bin/env bash
# Auto-generated by croam install-shim.sh. Do not edit.
exec croam launch "$@"
```

4. Make it executable: `chmod +x $(which claude-real | xargs dirname)/claude`

## cctakeover transition

If you previously used `cctakeover`, install a shell alias so existing muscle
memory works:

```bash
# Verify and install.
bash scripts/install-cctakeover-alias.sh

# Undo.
bash scripts/install-cctakeover-alias.sh --uninstall
```

The script appends `alias cctakeover='croam'` to `~/.zshrc` (if `$SHELL` ends
in `zsh`) or `~/.bashrc` (otherwise). It is idempotent and writes atomically.

Alternatively add the alias manually:

```bash
echo "alias cctakeover='croam'" >> ~/.zshrc   # or ~/.bashrc
```
